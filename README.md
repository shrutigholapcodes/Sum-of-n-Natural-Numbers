#Sum of 'n' Natural Numbers

A simple Java program which inputs the value of 'n' from the user and prints the sum of the first 'n' natural numbers

##Features

-Takes user input for the value of 'n'

-Uses a loop to calculate the sum

-Prints the sum

##What i learnt

-Validating n>0

-Using a do-while loop

-Using an accumulator variable (sum)
